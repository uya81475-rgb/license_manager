免許・資格 更新管理アプリ（ホーム画面追加対応版）

【内容】
- index.html：アプリ本体
- manifest.webmanifest：ホーム画面アイコン・アプリ表示設定
- service-worker.js：オフライン用キャッシュ
- icons/：アプリアイコン

【重要】
ホーム画面へのインストールとオフライン機能には HTTPS での公開が必要です。
このZIPを解凍し、フォルダー内のファイル一式をHTTPS対応の静的Webホスティングへアップロードしてください。
index.htmlだけを開く（file://）方法では、PWAインストールとService Workerは動作しません。

【スマホへの追加】
Android（Chrome）：公開URLを開く → メニュー →「アプリをインストール」または「ホーム画面に追加」。
iPhone（Safari）：公開URLを開く → 共有ボタン →「ホーム画面に追加」。

【データについて】
登録データはブラウザ内に保存されます。端末間で自動同期されません。機種変更・ブラウザデータ削除に備え、アプリ内の「データを書き出す」でバックアップしてください。
期限のお知らせはアプリを開いた時の画面内チェックです。閉じている間のプッシュ通知は実装していません。
